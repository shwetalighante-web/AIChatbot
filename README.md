# AI Chatbot

## Description
A Java-based AI chatbot that provides interactive communication using simple Natural Language Processing (NLP) techniques and rule-based responses.

## Features
- Interactive user communication
- NLP-style text processing
- Rule-based responses
- Frequently Asked Questions (FAQ)
- Java-based implementation
- Console-based interface

## Technologies Used
- Java
- Object-Oriented Programming
- String Processing
- Conditional Statements
- Scanner

## Chatbot Topics
The chatbot can answer questions related to:
- Java
- C Programming
- Data Structures and Algorithms
- Arrays
- Linked Lists
- Stacks
- Queues
- OOP concepts

## How to Run
1. Open `Main.java`.
2. Compile the Java program.
3. Run the program.
4. Type a question or message.
5. Type `bye` to exit.

## Project Objective
The objective of this project is to develop a basic Java chatbot that demonstrates interactive communication, NLP-style text processing, and rule-based responses.
